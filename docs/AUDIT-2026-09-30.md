## Architecture

- Six standalone top-level skills, each with `SKILL.md`, metadata, and 5–6 reference files. `creative-web-studio` is the broad coordinator; five others cover DOM motion, 3D, shader work, reference-led rebuilds, and QA.
- Three static demo sites and one Vite/React/TypeScript demo. `scripts/build-pages-site.mjs` assembles six skill pages plus four demos; GitHub Actions CI validates and Pages publishes on `main`.
- Only Asme has a package manifest and lockfile. The repo root has no package manifest, so Harness bootstrap found no root build/test commands. Existing CI knows the nested commands, but the Harness command map does not yet expose them.
- Static demo resources include Google Fonts, Unsplash images, one CloudFront video, and a pinned Three.js CDN import. Fallbacks exist in source, but external availability and exact browser behavior need runtime checks.
