Use these references for analysis practice, not cloning.

## Five-question reference analysis

1. What is the **one idea** making the reference memorable?
2. Which parts are generic techniques vs distinctive expression?
3. What would still work if the color/type/assets were removed?
4. Which two or more major dimensions will change in the new design?
5. What simpler implementation could preserve the useful principle?

If the answer to #4 is “none”, the rebuild is probably too close.
