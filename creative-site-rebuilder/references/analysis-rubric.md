# Reference Site Analysis Rubric

## Static composition
Document viewport, max width, grid, dominant alignments, type scale, negative space, crop logic, background fields, recurring shapes, and density rhythm.

## Motion
For each major element note trigger, start state, end state, direction, duration/progress, easing character, stagger, scroll linkage, reverse behavior, and whether the element persists across scenes.

## Scroll
Classify native, smooth, pin/sticky, scrub, snap, horizontal, or nested scroll. Note where normal browser behavior is preserved or modified.

## GPU clues
Look for perspective-correct object rotation, continuous shader distortion, canvas texture behavior, post-processing, particles, or DOM content mirrored into WebGL.

## Responsive
Determine what is actually redesigned: order, crop, camera, pin duration, interaction, density, typography, and whether 3D is replaced.

## Uncertainty
Mark each inference high/medium/low confidence. Never present guessed implementation details as facts.
