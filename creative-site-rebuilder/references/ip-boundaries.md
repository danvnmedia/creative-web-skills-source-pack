# IP and Reconstruction Boundaries

Focus on techniques and broad style characteristics. Reimplement from first principles.

Do not bundle copied source, proprietary prompt text, logos, paid assets, illustrations, 3D models, videos, or site copy unless the user owns or licenses them.

When a reference is highly distinctive, alter substantial creative choices rather than aiming for an indistinguishable clone. Generic interaction ideas — e.g. parallax, sticky sections, shared-element transitions, image displacement — can be reimplemented with original content and composition.

If the user supplies assets/code and states they have rights, work from those materials while still preserving security and licensing constraints of dependencies.
