# Rebuild Checklist

- semantic content complete before spectacle
- primary hierarchy recognizable in first frame
- original art direction established
- no copied proprietary assets/code/text
- one coherent motion grammar
- scroll behavior reversible and understandable
- signature interaction works with mouse, touch, and keyboard where relevant
- mobile re-choreographed
- reduced motion designed
- 3D/shader has fallback
- canvas/resources clean up correctly
- performance measured before final polish
