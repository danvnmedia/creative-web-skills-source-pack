# Build-ready AI Prompt Blueprint

Use this when the requested deliverable is a prompt for Codex, Claude Code, Cursor, Lovable, Bolt, v0, or another coding agent.

## Required blocks
1. **Role and objective** — what to build and why it should feel a certain way.
2. **Experience thesis** — one concrete metaphor or spatial rule.
3. **Non-negotiables** — framework, routes, content, brand assets, browser/device constraints.
4. **Art direction** — type, composition, palette, media treatment, negative space, material language.
5. **Scene-by-scene choreography** — still frame + entry + active + exit + bridge.
6. **Interaction state table** — idle / hover / press / focus / active / loading / error where relevant.
7. **Motion grammar** — 2–4 motifs, timing families, easing logic, scroll semantics.
8. **3D/shader spec** — only when needed: scene graph, camera, lights, materials, animation source, interaction, fallback.
9. **Responsive choreography** — what changes structurally on tablet/mobile, not just scaling.
10. **Reduced motion** — designed alternate states.
11. **Performance budget** — bundle, media, DPR, draw calls/scene complexity, loading strategy, CWV targets.
12. **Implementation rules** — component boundaries, client/server boundaries, cleanup, lazy imports, error handling.
13. **Acceptance criteria** — visual, interaction, accessibility, performance, browser checks.

## Prompting style
Write executable instructions. Avoid adjectives without mechanics. Replace “make it cinematic” with “use one persistent product object that scales from 28vw to full bleed, then becomes the mask for chapter two.” Replace “smooth animations” with explicit trigger, duration/progress mapping, and reduced-motion behavior.

## Never request
- copying source code from a reference site
- downloading proprietary assets without permission
- exact cloning of a distinctive site when an inspired reinterpretation will meet the goal
