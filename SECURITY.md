# Security Policy

## Supported version

Security fixes are applied to the latest revision of the `main` branch. Older commits and forks are not maintained by this project.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow:

https://github.com/danvnmedia/creative-web-skills-source-pack/security/advisories/new

Include the affected path, impact, reproduction steps, and any suggested mitigation. Remove credentials, personal data, and unrelated private information from the report.

Do not open a public issue for an undisclosed vulnerability. Please allow maintainers a reasonable period to validate and address the report before public disclosure.

This project contains instructional material and browser showcases. Reports should identify a concrete security impact rather than only a general best-practice preference.
