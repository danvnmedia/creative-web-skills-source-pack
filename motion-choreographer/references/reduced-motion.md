# Reduced Motion Design

Treat `prefers-reduced-motion: reduce` as a design mode.

Replace:
- large translations → short fade/cut
- scale tunnel/zoom → crop or opacity transition
- continuous parallax → static composition
- scrubbed camera motion → stepped content states
- autoplay spinning objects → static hero or user-controlled interaction
- long stagger → immediate/short group reveal

Keep:
- hierarchy
- state feedback
- focus/press clarity
- essential sequence information, presented without vestibular-heavy movement

Never hide content because an animation is disabled.
