## Showcase extraction template

For one interaction, write:

- **Trigger:** scroll / hover / click / drag / route / time.
- **Start state:** exact visual state before motion.
- **End state:** exact state after motion.
- **Continuity object:** what survives the transition.
- **Easing character:** crisp / elastic / heavy / cinematic / linear scrub.
- **Mobile translation:** how behavior changes without hover or long pinning.
- **Reduced-motion translation:** what remains when spatial motion is reduced.

If those seven fields cannot be described, the reference has not been analyzed deeply enough.
